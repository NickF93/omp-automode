# omp-automode

An [oh-my-pi](https://github.com/can1357/oh-my-pi) (OMP) plugin that lets the
agent work without per-action approval prompts. Before a tool call runs, an
independent AI reviewer checks it against a risk policy and the conversation, then
allows it or blocks it with a reason the agent must follow. The reviewer's model
and reasoning effort are configurable.

Status: no implementation yet.
